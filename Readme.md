# Лабораторная работа №1 - git

### Вариант 8. 

«Работа с Git reflog для восстановления удаленных или потерянных Commit»:

Запустите Git reflog, чтобы просмотреть историю действий ветвя-ми.

Переместитесь на любой предыдущий коммит. Используйте коман-ду git reset --hard HEAD~1. Это удалит последний коммит и все изме-нения, внесенные в него.

Изучите вывод Git reflog, чтобы найти удаленный коммит или из-менения, которые были потеряны. Скопируйте хэш удаленного комми-та, который вы хотите восстановить.

Создайте новую ветвь на основе хэша удаленного коммита с по-мощью команды git checkout -b <branch_name> <commit_hash>. Пере-ключитесь на новую ветвь и убедитесь, что удаленный коммит успешно восстановлен.

Просмотрите историю изменений с помощью Git log, чтобы убе-диться, что удаленный коммит или потерянные изменения были успешно восстановлены.

Закоммитите восстановленные изменения. Убедитесь, что ваш ре-позиторий находится в актуальном состоянии и все изменения сохра-нены.
